# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Instead, please report privately by emailing the maintainer or using GitHub's private vulnerability reporting feature (Security tab → Report a vulnerability).

You can expect a response within 48 hours. We will:

1. Acknowledge your report
2. Investigate and confirm the issue
3. Release a fix as soon as possible
4. Credit you in the release notes (if you wish)

## Thank You

Security research makes this project better for everyone. 🙏
