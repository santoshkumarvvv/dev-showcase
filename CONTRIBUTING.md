# Contributing to dev-showcase

Thanks for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/dev-showcase.git`
3. **Create a branch**: `git checkout -b feature/your-feature-name`
4. **Make changes** following the existing code style
5. **Run tests**: `flutter test && flutter analyze`
6. **Commit** with a clear message
7. **Push** and open a Pull Request

## Code Style

- Follow Dart's official style guide (`dart format .`)
- Run `flutter analyze` before committing — zero warnings required
- Write tests for new features
- Keep commits atomic and descriptive

## Pull Request Guidelines

- One feature or fix per PR
- Update docs if behavior changes
- Link related issues in the PR description
- Fill out the PR template completely
